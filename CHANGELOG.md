# Changelog

## 1.0.0 - 2026-10-16

- First release of the Lite edition: archive of every outgoing mail (addresses, bodies, attachment names and sizes, class, tags, metadata), redaction before storing, envelope-only and excluded classes, `sentfold-lite:prune`. Own namespace, table and config (`sentfold-lite`), so it never clashes with the full Sentfold.
